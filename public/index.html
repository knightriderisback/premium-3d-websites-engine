// 03. DEVELOPER TOOLING

FORGE CUSTOM 3D SITES IN SECONDS

The bundled 3d-forge.sh shell engine automates video frame slicing via FFmpeg (Lanczos 24fps) or generates procedural WebGL particle simulations with zero dependencies.

01. Extracts 120 high-fidelity WebP frames with optimal compression
02. Generates complete Tailwind + GSAP ScrollTrigger canvas scaffold
03. Injects AI Concierge speech synthesis and spatial layout
bash terminal — 3d-forge.sh 
# 1. Clone & Enter Repository
git clone https://github.com/knightriderisback/premium-3d-websites-engine.git
cd premium-3d-websites-engine

# 2. Forge Custom 3D Experiences (Procedural or Video)
./3d-forge.sh coffee [video.mp4]    # Generates ./dist-coffee
./3d-forge.sh burger [video.mp4]    # Generates ./dist-burger
./3d-forge.sh camera [video.mp4]    # Generates ./dist-camera

# 3. Instant Vercel Edge Deployment
vercel --prod
